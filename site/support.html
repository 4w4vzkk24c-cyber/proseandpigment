Prose & Pigment

Support

Prose & Pigment is a reader for Markdown, text and code files on iPhone and iPad. It shows a file as a typeset page. It reads files; it does not edit them.

Questions, bugs and suggestions go to hello@crossedkeys.co. One person reads that address, and it is me.

Opening a file

From the Files app

  1. Find a Markdown, plain-text or source-code file.
  2. Use Share or Open With, and choose Prose. That is the app’s name on the home screen.

The app never asks to be the default for any kind of file, so look for Prose in the list.

From inside the app

  1. Open the app and tap Open a file.
  2. Pick a file.

Pasted text

Tap Paste your clipboard on the home screen. iOS asks whether to allow the paste. The app shows the text as a page, the same way it shows a file, and never saves it.

The back button at the top left closes a document. The home screen also has a welcome document that shows everything the app can display.

What it shows

  • Headings, lists, quotes, links and emphasis
  • Code blocks in colour, in 19 languages: Bash, C, C++, CSS, diff, Go, Java, JavaScript, JSON, Kotlin, Markdown, Python, Ruby, Rust, SQL, Swift, TypeScript, XML and YAML
  • Source files on their own, such as a .py or .swift file, shown highlighted
  • Highlighted text, tables and callouts

The app hides front matter, the block between --- lines at the top of a note.

Links to web pages open in Safari. The app does not load pictures from the internet, so an image that points to a web address will not appear.

When a file won’t open

The app reads text saved as UTF-8. When it can’t show a file, it says why:

  • “This isn’t a file the app can read. It reads Markdown, plain text and source code, as UTF-8 text.” The file is not text, or is in another encoding. Trying again would not change that, so this screen has no button.
  • “This file is empty. If something is still writing it, try again in a moment.” Tap Retry when the file has something in it.
  • “This file couldn’t be read. It hasn’t been changed.” Tap Retry. The app never changes a file, whatever happens.
  • “This file is too large for the app to read. It reads files up to 5 MB.” This screen has no button.
  • “This file couldn’t be displayed. It hasn’t been changed.” The file was read, but the page could not be made from it. Trying again would not change that, so this screen has no button.

Pasted text has two sentences of its own, and neither screen has a button:

  • “The clipboard is too large to show. This app displays pasted text up to 5 MB.”
  • “This text couldn’t be displayed.”

The back button at the top left leaves any of these screens.

Themes and appearance

Tap the gear, on the home screen or while reading, to open Settings.

  • Appearance: Light, Dark, or System, which follows your device.
  • Themes: choose one light theme and one dark theme. In System appearance the page switches with your device.
  • Each theme pairs a reading font with a code font. All fonts are built in and work offline.
  • Acknowledgements in Settings lists the fonts and themes and their licences.

Files in iCloud Drive

If a file is in iCloud Drive but not yet on your device, the app asks iOS to download it and shows “Downloading from iCloud…” until it arrives.

If the download is slow or never starts, the app says so and offers Retry. Check your connection and that you are signed in to iCloud, then tap Retry. The back button at the top left leaves.

Privacy

The app collects no data. It reads your files on your device and never uploads them. The privacy policy has the detail.

Requirements

iOS 18 or later, on iPhone or iPad.
