# Setting body text

Start with the **measure**, the length of a line. Too long and the eye loses its place on the way back; too short and it never settles. Then open the `line-height` until the lines stop touching.

```css
/* Narrow measure, open leading. */
article {
  max-width: 38rem;
  font-size: 1.125rem;
  line-height: 1.55;
  font-family:
    "Source Serif 4", serif;
}
```

> Set the measure first. Everything after it is adjustment.

| Setting | Value | Change it when |
|---|---|---|
| Measure | `38rem` | the typeface runs wide |
| Size | `1.125rem` | the text is read at a distance |
| Leading | `1.55` | the lines get longer |

import SwiftUI

// A named colour in a theme.
struct Pigment {
  let name: String
  let hex: Int

  func color() -> Color {
    let r = Double(hex >> 16 & 0xFF)
    let g = Double(hex >> 8 & 0xFF)
    let b = Double(hex & 0xFF)
    return Color(
      red: r / 255, green: g / 255,
      blue: b / 255)
  }
}

let lead = Pigment(
  name: "Vermilion", hex: 0xD2452D)

What it shows

  • Headings, lists, quotes, links and emphasis
  • Code blocks in colour, in 19 languages, including Swift, Python, JavaScript, TypeScript, Rust, Go, SQL and shell
  • Source files on their own: open a .py or .swift file and read it highlighted
  • Tables, task lists, callouts and footnotes
  • More than 30 themes, light and dark, each with its own reading font and code font

What it doesn’t do

It doesn’t edit. It doesn’t sync. It keeps no library.

It reads the file you hand it. It doesn’t take pasted or shared text yet; for now it opens files.

Private

No account, no analytics, no ads. Files are read on your device and never uploaded, and the app loads nothing from the internet. The privacy policy says the same thing at more length.

Who makes it

I do, alone. I built it to read what my agents write. Questions go to hello@crossedkeys.co, and the support page covers how the app works.
