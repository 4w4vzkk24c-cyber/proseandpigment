# What I changed

The slow step was reading the config on **every request**. I cache it now, in `load_config`.

```python
# Read once, then reuse.
@lru_cache(maxsize=1)
def load_config(path: str) -> dict:
    with open(path) as f:
        return json.load(f)
```

Naming a colour

Give every colour a name and write its value once. A Pigment keeps the two together.

// One name, one value.
struct Pigment {
  let name: String
  let hex: Int

  func red() -> Double {
    Double(hex >> 16 & 0xFF) / 255
  }
}

let lead = Pigment(
  name: "Vermilion", hex: 0xD2452D)

# Naming a colour

Give every colour a **name** and write its value once. A `Pigment` keeps the two together.

```swift
// One name, one value.
struct Pigment {
  let name: String
  let hex: Int

  func red() -> Double {
    Double(hex >> 16 & 0xFF) / 255
  }
}

let lead = Pigment(
  name: "Vermilion", hex: 0xD2452D)
```

> Write the value once. Every view reads it from there.

| Pigment | Value | Colours |
|---|---|---|
| Vermilion | `0xD2452D` | keywords |
| Indigo | `0x34446E` | function names |
| Green earth | `0x6E8B5B` | strings |

What it shows

  • Headings, lists, quotes, links and emphasis, set as a page instead of as symbols
  • Code blocks in colour, in 19 languages, including Swift, Python, JavaScript, TypeScript, Rust, Go, SQL and shell
  • Source files too: open a .py or .swift file and read it in colour
  • Tables, task lists and callouts
  • More than 30 themes. Pick one for light and one for dark, and the page follows your device
  • Files from the Files app, including iCloud Drive

What it doesn’t do

It doesn’t edit. It doesn’t sync. It keeps no library.

It reads the file you hand it. It doesn’t take pasted or shared text yet; for now it opens files.

Private

No account, no analytics, no ads. The app reads your files on your device, never uploads them, and loads nothing from the internet. The privacy policy says the same thing at more length.

Who makes it

I do, alone. I built it to read what my agents write. Questions go to hello@crossedkeys.co, and the support page covers how the app works.
