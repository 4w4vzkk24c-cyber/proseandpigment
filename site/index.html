# Renaming a batch of photos

You can do this with a **short script**. It reads each file's date and builds the new name from it, so the order of the files doesn't matter.

```python
# Rename photos to their capture date.
def rename_all(folder: Path, start: int = 1):
    for photo in sorted(folder.glob("*.jpg")):
        stamp = capture_date(photo)
        photo.rename(folder / f"{stamp}.jpg")
```

> Run it on a copy of the folder first.

| Option | Default | Effect |

What it shows

  • Headings, lists, quotes, links and emphasis
  • Code blocks in colour, in 19 languages, including Swift, Python, JavaScript, TypeScript, Rust, Go, SQL and shell
  • Source files on their own: open a .py or .swift file and read it highlighted
  • Tables, task lists, callouts and footnotes
  • More than 30 themes, light and dark, each with its own reading font and code font

What it doesn’t do

It doesn’t edit, it doesn’t sync, and it keeps no library. It reads the file you hand it. It doesn’t take pasted or shared text yet; for now it opens files.

Private

No account, no analytics, no ads. Files are read on your device and never uploaded, and the app loads nothing from the internet. The privacy policy says the same thing at more length.
